FAQ about the Multi-Lane Stick Pack Machine

What fill weight can a stick pack machine handle?

Typical stick packs hold 1–50 g (or ml). The fill range depends on stick width and length; tell us your target weight and stick size and we will select the screw, cup or pump.

Can one machine pack both powder and liquid?

No — the dosing system differs. Powder uses auger screws, granules use volumetric cups and liquids use pumps. The bag-forming mainframe is the same, so we configure the doser for your product.

How many operators are needed?

One operator can run the machine: loading film, refilling the hopper (or using an automatic feeder) and checking output.
